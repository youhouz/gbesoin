# Gbesoin – L'app du peuple

Marketplace locale centrée sur les **demandes** (pas les offres).

**Lien direct une fois Pages activé :** https://youhouz.github.io/gbesoin/

## Activer GitHub Pages (10 secondes)
1. Va sur https://github.com/youhouz/gbesoin/settings/pages
2. Sous **Source**, choisis **Deploy from a branch**
3. Branch : `main` / folder : `/ (root)`
4. Clique **Save**

L'app sera en ligne en 1-2 minutes.

## Concept
Tu as besoin de quelque chose ? Tu postes.  
Les particuliers et les pros te répondent en direct.  
Visibilité maximale, simplicité maximale.

Optimisée pour l'**Île-de-France**.

## Fonctionnalités
- Feed de demandes avec filtres catégorie + département
- Publication rapide (photo + texte + catégorie + localisation)
- Réponses directes sur chaque demande
- Données persistantes (localStorage)
- Design mobile-first moderne
